# Subtitle Downloader Extension

A simple browser extension to easily download subtitle files from your favorite streaming services.

### Supported Sites:
- [x] FPT Play
- [x] Vieon
- [x] Crunchyroll

### Main features:

- Detects and allows downloading of the original subtitle file (`.ass`, `.vtt`, etc.).
- Easy to use, with a download button integrated directly into the page.

---

## INTRODUCTION

Ever wanted to save subtitles from a movie or show for language learning, offline viewing, or personal use? This extension solves that problem. It automatically detects when a video player loads a subtitle file on supported streaming sites and provides a simple, one-click button to download it directly to your computer.

---

## GET STARTED

Since this extension is not on the Chrome Web Store, you can install it manually by following these steps:

1.  **Download this repo**
    * Click the green `<> Code` button on the GitHub repository page.
    * Select `Download ZIP`.
    * Unzip the downloaded file (`subtitle-downloader-extension.zip`) into a folder you can easily find.

2.  **Open your browser's extensions page**
    * Open your Chromium-based browser (Google Chrome, Microsoft Edge, Brave, etc.).
    * Navigate to `chrome://extensions`. You can copy and paste this into your address bar.

3.  **Enable Developer Mode**
    * In the top right corner of the extensions page, find the **Developer mode** toggle and turn it **ON**.

    

4.  **Load the extension**
    * Three new buttons will appear: "Load unpacked", "Pack extension", and "Update".
    * Click on the **Load unpacked** button.
    * A file selection window will open. Navigate to and select the folder you unzipped in Step 1.

5.  **Done!**
    * The "Subtitle Downloader Extension" will now appear in your list of extensions and is ready to use!

---

## HOW TO USE

1.  Navigate to one of the supported sites.
2.  Play a video that has subtitles.
3.  A small window will appear on top of the page and list out all the available subtitle.
4.  Click the button to download the currently active subtitle file.
